# ZenWreath originality review — 2026-10-12

This is a source review and risk-reduction record, not an infringement opinion,
trademark clearance, or guarantee against a lawsuit.

## Changes in version 38

- Replaced the pointed character hat with a rounded cap; migrated old `hood`
  appearance values to `beret` while preserving other saved choices.
- Default keeper wears an amber travel coat with lake-colored trim, rather than
  a green tunic and pointed hat. Cosmetic options have distinct coats, café
  aprons, knit patterns, rounded headwear, leaf pins, and satchels.
- Bucklers use a wreath, oak grain, or petal motif; no franchise crest.
- Music menu is Grove chimes. Played notes use synthesized two-part bell tones;
  no sampled soundtrack. Existing note indices and profile settings remain
  compatible. Melodies are short sequences defined in project source.
- Renamed the village guide to Mira; the legacy internal ID is kept for saves.
- No Nintendo character names, logos, franchise locations, extracted sprites,
  or audio recordings were found in active game source during the text/asset
  review. This observation does not establish that every similarity is lawful.
- The lantern app icon is a code-drawn geometric lantern. In-game art is drawn
  by this project's Canvas routines. Built-in fonts and system emoji are used;
  their appearance depends on the device. Dependencies retain their own licenses.
